# PeerMentor Platform — Платформа менторства для первокурсников

## О проекте
PeerMentor — это веб-платформа для организации студенческого наставничества.
Платформа помогает первокурсникам быстрее адаптироваться к университетской
среде через персональных наставников из числа старшекурсников.

## Быстрый старт (для разработчиков)
1. Клонировать репозиторий
2. Скопировать `.env.example` → `.env` и заполнить переменные
3. Запустить `docker compose up --build`
4. Backend доступен на `http://localhost:8000`
5. Frontend доступен на `http://localhost:5173`
6. Админ-панель: `http://localhost:8000/admin`

## Архитектура
[Схема: Frontend (React) ↔ API (Django REST) ↔ PostgreSQL]
                                  ↕ WebSocket
                          Django Channels ↔ Redis
